### Added
- A workspace row shows how far its branch is from its upstream (`↑2 ↓1`), and each workspace's
  folder glyph keeps a color of its own.
- A pane's address in terminal text (`w1:p3`, or `vps/w1:p3` for another PC) is a link while
  that pane is open: Ctrl-click, or Cmd-click on a Mac, shows it.

### Changed
- A file path in a terminal is underlined only when the pane's PC finds the file.
